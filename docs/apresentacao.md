# Apresentação do Sistema Controle CPO

O **Controle CPO** (Comando de Policiamento Ordinário) é uma plataforma integrada para a gestão, monitoramento e relatórios de operações policiais. O sistema foi desenvolvido para centralizar informações que anteriormente eram dispersas, permitindo uma visão estratégica e em tempo real do emprego do efetivo e recursos.

## 🎯 Objetivos do Sistema

- **Centralização de Dados:** Unificar o registro de operações em uma única base de dados (Google Sheets).
- **Transparência e Auditoria:** Manter um histórico detalhado de quem criou ou alterou cada registro.
- **Visibilidade Estratégica:** Prover dashboards e relatórios automáticos para tomada de decisão.
- **Facilidade de Acesso:** Interface web responsiva acessível de qualquer dispositivo com permissão.

## 🚀 Principais Funcionalidades

### 1. Dashboard Inteligente
Visualização rápida dos principais indicadores das operações, incluindo status atual, distribuição por município e resumo de recursos empregados (efetivo e viaturas).

### 2. Gestão de Operações
Interface intuitiva para cadastrar novas operações ou apoios, editar registros existentes e acompanhar o status (Rascunho, Ativa, Finalizada, etc.).

### 3. Calendário Operacional
Visualização das operações futuras e em andamento em formato de calendário, facilitando o planejamento de longo prazo e evitando sobreposições de recursos.

### 4. Relatórios e Auditoria
Geração de relatórios detalhados para análise de desempenho e conformidade, além de uma tela de auditoria que registra todas as movimentações no sistema.

### 5. Integração com Mapas
Visualização geográfica das operações, permitindo identificar áreas de maior concentração de policiamento.

## 🛠️ Benefícios

- **Redução de Erros:** Validação de campos obrigatórios e formatos padronizados (Nº SEI, Cód. SISEG).
- **Agilidade:** Sincronização automática com planilhas Google, eliminando a necessidade de envio manual de arquivos.
- **Segurança:** Controle de acesso via login e registro de logs de atividade.
