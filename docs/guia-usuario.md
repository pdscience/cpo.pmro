# Guia do Usuário - Controle CPO

Este guia orienta os operadores sobre como realizar as tarefas diárias no sistema.

## 🔐 Acesso ao Sistema

1. Acesse o URL do sistema fornecido pelo administrador.
2. Na tela de login, insira suas credenciais.
3. Se for o primeiro acesso, certifique-se de configurar a URL da API na aba **Configuração API** (apenas usuários autorizados).

## ➕ Cadastrando uma Nova Operação

1. Clique no menu **Nova Operação** na barra lateral.
2. Preencha os campos obrigatórios:
   - **Data de Início:** Quando a operação começará.
   - **Organização Policial Militar (OPM):** Unidade responsável.
   - **Município:** Localidade da operação.
   - **Nº SEI:** Número do processo administrativo.
3. Insira a quantidade de **Efetivo** e **Viaturas**.
4. Clique em **Salvar**. A operação será criada inicialmente com o status "Rascunho".

## 📊 Visualizando e Editando Operações

No menu **Operações**, você verá uma lista de todos os registros.
- Use a **Barra de Pesquisa** para filtrar por nome, município ou OPM.
- Clique em **Ver Detalhes** (ícone de olho) para visualizar todas as informações.
- Clique em **Editar** para modificar dados. Lembre-se que alterações geram registros na auditoria.

## 📅 Calendário de Operações

O **Calendário** apresenta uma visão temporal.
- Operações futuras aparecem destacadas.
- Clique em um evento no calendário para ver um resumo da operação.

## 📈 Relatórios e Estatísticas

O menu **Relatórios** oferece gráficos e tabelas consolidadas.
- Veja o total de operações por mês.
- Analise o emprego de efetivo total no período selecionado.
- Os dados podem ser filtrados para análises específicas.

## 🕵️ Auditoria

Caso precise verificar quem realizou uma mudança em um registro:
1. Acesse o menu **Auditoria**.
2. O sistema exibirá o histórico de criação e atualização, incluindo o usuário responsável e a data/hora exata da modificação.
